# Правила frontend и зачем они нужны

Сначала прочитайте инструкции техлида, package.json, tsconfig и соседний код. Целевой стек: React, TypeScript, pnpm, ESLint, Zod, Zustand, Vitest, Node.js. Реальный статус инструментов приведён в [README](../README.md). Skylos заявлен в задании, но область применения/версия не согласованы; не заменяйте им ESLint и не запускайте выдуманные команды.

| Решение | Зачем / пример ошибки |
| --- | --- |
| JSON проверяется на границе через согласованную Zod-схему | `as Report` не преобразует строку в число и не отвергает неизвестный статус |
| DTO отражает реальный API | Нельзя выдумать endpoint `/rerun` только потому, что он есть в учебном примере |
| Zustand хранит действительно общее состояние; используйте selectors | Глобальное изменение не должно заставлять всё приложение перерисовываться; локальный input не требует store |
| Запрос привязан к выбранному run/PR; устаревший ответ игнорируется | Ответ A может прийти позже B и показать чужой отчёт |
| Обрабатывайте loading, empty, error, partial и stale | Отказ модели с пустыми findings не означает «всё хорошо» |
| JWT и VCS secrets не попадают в URL, логи и произвольный persistent storage | История/телеметрия не должны раскрывать авторизацию; следуйте принятой auth-схеме |
| Скрытая кнопка не заменяет backend authorization | Чужой run можно запросить напрямую, поэтому сервер проверяет права |
| Rerun получает новый ключ действия; retry сохраняет прежний | Пользовательское намерение отличается от повторной доставки запроса |
| Текст ревью выводится безопасно; опасный HTML не исполняется | Контент модели/PR может содержать HTML и инструкции |

Снимок отчёта включает run_id и фиксированный SHA. Старый отчёт не меняется вслед за обновлением PR. Перед публикацией комментариев актуальность и доступ проверяет backend. VcsProvider, RabbitMQ, PostgreSQL, Ollama и секреты интеграции остаются за серверной границей. Redis и distributed rate limit — открытые решения команды, а не скрытые зависимости UI.

Для fetch используйте AbortController и/или счётчик поколения запроса; отмена сама по себе не гарантирует, что уже завершившийся парсинг не обновит состояние. Cleanup при unmount обязателен там, где эффект продолжает работу. Проверяйте сценарий быстрых переключений.

Коммит: `ISSUEID: точная тема задачи`. В PR — изменение поведения, связанные issues, выполненные проверки и ограничения. Не добавляйте AGENTS.md и не меняйте конфигурацию целого проекта ради одного шаблона.
