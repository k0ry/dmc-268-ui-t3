description: Реализует frontend задачи AI-review проекта на React/TypeScript с проверкой API-данных, состояниями UI и защитой от устаревших ответов. Использовать при изменении UI-кода.
---

Прочитай [правила](../../rules/frontend.md), package.json, tsconfig, компонент и вызываемый API. Установи, какие инструменты реально установлены.

1. Опиши действие пользователя, контракт, обычный ответ и отказ по [шаблону](../../templates/implement.md). Не создавай API из догадки.
2. Меняй существующую структуру. Проверяй внешние DTO на границе; держи общее состояние минимальным. Не подключай Zod/Zustand/новый store без необходимости и согласованного scope.
3. Привяжи отображение к текущему run/PR, обработай быстрые переключения, cleanup, loading/error/partial. Проверь клавиатурную доступность интерактивного элемента и понятный текст ошибки.
4. Добавь нужную проверку поведения из [плана](../../templates/test-plan.md); сравни с [учебным примером](../../templates/report-loader.ts.example), если задача затрагивает гонку запросов.
5. Выполни существующие build/lint/test scripts. Если инструмента ещё нет, укажи это, а не объявляй тесты пройденными. Объясни на одном сценарии, почему решение работает.
